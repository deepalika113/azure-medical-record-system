# azure-medical-record-system
Secure and scalable medical record system using Microsoft Azure
## Conclusion

The Azure Medical Record System provides a secure, scalable, and centralized platform for hospitals to store and manage patient information. By using Azure SQL Database, patient data is stored safely; Azure Blob Storage handles medical images efficiently. Role-Based Access Control ensures only authorized users can access sensitive data, and Resource Locks prevent accidental deletion of critical resources.

## Future Scope

- Integrate AI/ML features for predictive analytics and diagnostics.  
- Add mobile and web portals for easier access to patient records.  
- Implement Azure Monitor for auditing and tracking system activity.  
- Expand to support interoperability with other hospital systems.
