## Implementation Overview

This document explains the steps used to design and configure a secure and scalable medical record system using Microsoft Azure services.
The Azure Medical Record System uses Azure SQL Database to store patient data securely. Medical images are stored in Azure Blob Storage, providing scalable storage. Access control is managed using Role-Based Access Control (RBAC) to ensure only authorized personnel can view or modify records. Resource Locks are applied to prevent accidental deletion of critical resources.
